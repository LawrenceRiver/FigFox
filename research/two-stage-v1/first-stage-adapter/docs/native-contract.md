# Public planning and verification schema

Read inputs/native-contract.json and inputs/method-pack.json. Read native source/manual only if enabled and explicitly listed. Use availability_manifest; no implied capability follows from a category.

Program envelope: id,image_id="case",issue_ids,base_revision,phase="reconstructor",route,target_ids,depends_on,rcd_predescription,source_code (generated_python), args (enabled module_program only), optional relations/convergence/when/source_location. Preserve exact active issues and provide unresolved_reasons for unsupported obligations. generated_python receives INPUT_SVG and OUTPUT_SVG file paths; use standard-library xml.etree.ElementTree/math to construct your own scoped SVG geometry and write the complete SVG. Preserve stable IDs and neighbors. S1/D requirements remain active with self-authored geometry when methods are disabled. D-only and S2-only programs require empty depends_on.

Relations have id,predicate="contain"|"separate"|"legal_overlap",subject_id,object_id,reference_evidence; containment uses positive padding and separation positive min_gap. Convergence has max_iterations,alignment_checks,repairs. Checks have id,target_ids,reference_ids,mode,tolerance,reference_evidence. E/F retain the same required original-supported relations, bounded checks and two successful read-only checks. With methods disabled repairs must be []; author changes in source_code. Host read-only acceptance and scope guards apply equally.

A missing object's actual container_id is insertion scope only; it grants no authority to change existing descendants. Existing-target writes require independently linked explicit targets. Host may reject unprovable opaque insertion programs: retain unresolved obligations honestly. No native acceptance substitutes for source/before/candidate visual verification. No-op changes cannot resolve defects. Same three repair attempts and independent verifier apply.

ID navigation metadata and mandatory report bounding-box schema fields remain available. Numerical native measurement snapshots and hidden diagnostics are unavailable when methods are disabled. Ordinary visible SVG attributes remain readable. Report exact revision/evidence_hashes and actual region IDs. Use the supplied observation/pending/necessity/promotion contracts, immutable raw receipts and bounded same-slot local checks. Never infer an issue, coordinate or source identity from an asset name or a box alone.
