# Frozen prospective category profile: lean6-semantic-acs4-v2

Main inspection is exactly native lean6, in order F, E, B, S1, D, S2. The independent supplemental branch keeps its correspondence/completeness duty and may report any of the same coherent nine categories, F/E/B/S1/D/S2/A/C/S4, when that duty reveals the corresponding phenomenon. A/C/S4 are the additional taxonomy categories, not the only supplemental admission categories. This does not add a second full main-category sweep. S3 is outside this experiment. Category is immutable within a run, including uncertainty promotion and failed preflight; unsupported repairs remain unresolved.
