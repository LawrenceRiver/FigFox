# No-edit necessity requests inside the existing verifier

A planner may submit optional not_required_proposals:[{issue_id,source_evidence,before_evidence,why_qualified}]. Use each exact active required/uncertain ID at most once, with nonempty visible source evidence, before evidence and reason it may be qualified. Preserve every active issue object and a nonempty unresolved_reasons entry for each requested ID. Historical, pending, retired and foreign IDs cannot be requested. Programs cannot cite an ID that this plan proposes not to edit. Requests never remove queues, relabel categories/decisions, promote uncertainty, create permission or earn repair credit. Independently justified shared-target writes by other linked active issues still satisfy all existing scope, insertion, native guards and transaction rules.

Before native execution the host writes round-N/necessity-review-requests.json once with the raw planner SHA, before revision/evidence hashes and verbatim claims. The candidate record binds its SHA; mutations reject acceptance. This file is supplied only to the existing independent post-render verifier along with source/before/candidate and native receipts. It is not proof, and the verifier may reject any claim. No additional model/API slot, draft budget or fourth repair attempt is created.

The verifier uses only the existing confirmed resolved_ids/unresolved_ids/not_required partition and uncertainty_reviews. A defect present in BEFORE and resolved in candidate is a repair, never a prior false positive. A genuinely unresolved necessary defect remains unresolved. Omitted uncertainty remains uncertain, and confirmation follows the original full-current-issue rules preserving category/history. Source-required functional identity/parts, readable correct text and meaningful structure establish the necessary core; uncertain optional details neither erase it nor become required by default. Original S1 regular-solid topology, source-required faces/divisions and meaningful counts remain binding. No category changes evade guards.

Unchanged SVG cannot resolve confirmed or uncertain findings. not_required is independently evidenced false-positive adjudication, not repair credit. Protected regression rolls back the entire candidate and all proposed queue/binding/knowledge changes, retaining the original checkpoint. Pending observations continue through their separate existing lifecycle; these requests cannot adjudicate them. Max three repair attempts and original coordinates/SAM constraints remain unchanged.
