# DeepSeek：五类优先问题

独立入口 `experiments/review_priority_v1.py`，沿用 DeepSeek 接口、thinking enabled、单图一次请求。Luna 与旧 DeepSeek 实验代码保留。

三轮检查：原图PNG与初始SVG渲染PNG/代码 → 既有上游Crop配对 → 再次全部相同Crop配对。每轮优先检查E对齐、F交叠出框，再B字体公式、A知识内容和S1明显几何结构/比例错误。几何不等于照片内容相似度；照片、纹理和细小色差本轮不单独修改。

主动寻找最可疑的对齐和交叠候选，再对照原图反证，确认、排除或标不确定；禁止为数量编造真实错误。检查优先级不等于执行依赖顺序，先改结构/内容，最终布局与邻居复查。E/F循环未收敛回滚并保留未解决；A/B/S1未执行同样不得标完成。机械执行不等于视觉验收。

几何构建失败可用完整原图裁片回退。裁片需完整物件证据和四边核查，插入前检查坐标包含；RMBG可能损伤物件，不能自动当作成功。现有后端没有专用微粒子贝塞尔方法，不冒称已实现。

所有输入来自固定首次图像与上游证据。人工圈注与私有验收不进入准备器或请求。三张图属于开发回归；先前反馈参与通用规则设计，不能宣称独立盲测。
