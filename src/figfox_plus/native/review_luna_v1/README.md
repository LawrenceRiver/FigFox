# Luna v1（独立版本）

入口：`experiments/review_luna_v1.py`。沿用首次生成的 SVG 和上游既有 Crop 配对，每张独立输入、独立一次 OpenAI Responses 请求。模型 gpt-6-luna，输出上限 128000，无自动重试。原 DeepSeek review_pipeline 保留；baseline-hashes.json 记录原代码哈希。

E 对齐、F 交叠/出框是阻断完成的高优先级问题。每个确认问题必须有收敛检查，修复后重新测量最新现图 TP；循环仅运行已声明、限定目标的修复指令。连续两轮无报警才记 measured_converged。失败不提交该事务，保留未解决。数值对齐仅允许 0.5 像素测量误差。原图有意重叠须有来源证据。未检出的问题仍可能存在，测量通过不等于视觉通过。

sp_photo 插入前要求完整物件的原图语义观察、四边审视、原图整物件范围；裁片必须完全包含此范围。缺少依据、声明不完整或超出原图时拒绝。这是模型视觉声明加代码坐标检查，并非代码能独立证明物件完整；最终图像仍需验收。

一次 HTTP 模型请求不具备本地中途执行再返回模型的能力。本版本在一次请求中返回程序，本地按程序执行和循环复查；没有伪称 API 内部已执行。公开流程报告只陈述可核验观察、操作、结果及服务端提供的摘要。

人工圈图及私有验收文件不参与输入准备。旧三张图曾用于提示词开发，因此结果是开发集回归，不构成独立盲测的泛化结论。
