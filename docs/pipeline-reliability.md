# 主流程稳定性与验收边界

## 保留的生成流程

正式入口是 `python -m figfox_plus chain`，按已有顺序运行：

1. SAM 提供原图资产，由 GPT-5.5 一次生成完整 SVG。
2. 本地渲染、测量，准备原图与当前图的 1/2 Crop。
3. DeepSeek 整图发现问题，然后在同一会话内为已发现问题生成修复程序。
4. 按原有 F/E/S1/S2 回执条件，最多追加一次跟进。

检查记录完整且没有待处理问题时，沿用原来的发现后停止条件。正常长推理不会因累计字符数、总运行时间或费用目标而停止。

GPT 保持 `gpt-5.5 / medium`，明确设置官方最大输出额度 128,000；DeepSeek 主链保持 `deepseek-v4-flash-vision-exp / high` 和上游输出额度 393,216。输出额度包含推理，按实际用量估算费用。设置可查 `providers.py` 和 `review_problem_first_v13/transport.py`。

默认流程不拆图、不分批提示词、不删语义证据、不缩减历史推理，也不自动启用额外模型恢复或独立候选。显式的本地调试与历史恢复工具不属于默认主链。

## 复杂图与上下文

路径、重复工具说明和引用表采用可以完整还原的表示，整图、全部原有裁图、工具关联和同会话消息顺序保留。容量审计与编码记录写入请求目录；保守上界估算默认提示，不仅凭估算拒绝能正常提交的请求。

此优化减少重复表示开销，不扩大服务商真实上下文窗口。实际输入加输出预留仍可能超过窗口；服务端超限会记录为失败，不通过拆图、删证据或无限重试绕过。可完整还原文本也不等于已证明模型对所有图片的理解效果不变。

## SVG、执行与产物

- 本地规范化只处理可确定的 XML、字符转义、片段引用与 JSON 格式问题。资产绑定、真实源图位置、对象范围和有限几何仍须通过检查。
- TP 可选声明单独应用和回滚；`null` 可选参数可以省略。未知的非空对象引用或会改变实际范围的错误继续拒绝，不由宿主猜测坐标。
- 原图二维结构不得仅凭模型猜测变成立方体。立体修复使用原图证据；真实立体结构仍可走原有修复路径。颜色处理保留细描边。
- 修复依赖保留，包括与 F/E 共享作用范围的 D/S2 程序。单个程序失败或被拒绝会记录回执，并保留其他已提交的有效修复。
- PNG 在发布前实际解码。每个有效阶段保存 SVG/PNG，后续失败继续提供最后一组有效产物。Windows 文件暂时占用只做短暂、有界的本地重试。
- 生成的 Python 仍在隔离环境执行。缺少隔离组件明确失败，不降级为直接执行。

首稿已有完整可用回复时，优先本地解析和渲染；无法恢复时报告失败。默认不会额外调用模型重写首稿，不伪造空画布或整图贴图的成功。

## 异常监控与费用

有效进展包括新增推理、正文和工具参数；心跳、重复元数据与空白不算。DeepSeek 默认 5 分钟无内容提示、20 分钟无内容中断；GPT 首个可见内容之前 15 分钟提示进度暂不可见、最多 60 分钟无可见内容保护，开始可见输出后沿用 20 分钟保护。参数与通知见 [监控说明](experiment-monitoring.md)。

每图 1 USD 是默认提示目标，超出仍继续正常流程。只有显式选择硬预算时才预留完整请求费用，不足则在发送前拒绝整次请求，保留已有产物；不会通过砍输出额度适配预算。费用来自服务商报告用量的估算，缺失用量保持未确定，不等同供应商账单。

## 验证与已知边界

离线回归覆盖实际浏览器渲染、隔离执行、模拟流中断、产物回退、上下文还原、费用策略和问题回执，不调用模型：

```bash
python -m pip install pytest
python -m pytest -q
```

开发验证包含历史超限复杂图的重新完整运行，以及未参与此前优化的 CVPR 008、024 图。024 完成原有三个请求并生成有效 SVG/PNG，按记录用量估算约 0.68 USD；仍有被执行契约拒绝的程序，状态为 `completed_with_issues`。这些结果是开发证据，不是正式基准成绩。

出图、流程完成、问题修复落实和视觉验收分别报告。有 SVG/PNG 不代表所有问题都已修复。当前仍有实际上下文超限、不可恢复首稿、模型生成不合约修复程序、持续存储/网络故障等边界；尚未完成系统冻结后的大批未见图评估及与上游的严格同图能力对照。
