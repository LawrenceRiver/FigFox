# Validation status — 2026-10-24

The first-generation OpenAI request and the original DeepSeek detection, repair,
and conditional follow-up have been exercised on one historical development
figure with SAM disabled and code methods enabled. A transport failure interrupted
the first DeepSeek attempt; recovery reused the saved OpenAI output and submitted
the same detection input. This is a segmented integration check, not an
uninterrupted performance benchmark or a completed benchmark evaluation.

The three successful DeepSeek responses reported 111,429, 158,610, and 66,459 total
tokens. No provider context-limit error occurred in these responses. The local
capacity check remains an estimate and can still reject larger inputs; this
single figure does not establish capacity safety for the whole dataset.

Independent, anonymous model review against FigFox V2 found necessary gains and
a necessary regression: several process arrows and a subscript group improved,
while a correctly placed subscript prime became a superscript prime. Follow-up
improved one vector attachment, but formula and arrowhead problems remained.
These are model judgments, without a human sign-off. Neither passing execution
nor a `changed_unverified` receipt means that the image is visually correct.

A subsequent fixed-answer replay identified a host rejection of an existing
four-arrow endpoint repair. Allowing the scoped straight-path trim restored four
visible sampling arrowheads in anonymous visual review, with no necessary loss
observed. The release implements that structural exception without the pilot's
scene-specific distance caps; see [endpoint contract](arrow-endpoint-repair.md).
Replaying the saved program is local host evidence, not another API sample or
evidence that the remaining formula errors were repaired.

Local asset-contract fixes have separate fixed-answer replay evidence on two
figures. An unprompted Harness reconstruction also produced raster-equivalent
horizontal pixel-run paths; these preserve appearance, not semantic editability.
They do not establish that paid first-generation requests will choose that
representation or become cheaper. The production workflow retains the original
generation → detection → repair → conditional follow-up structure.

The historical 80-image SAM × code-method experiment is planned, not run. All
four assignments must use the same historical source IDs and hashes. S1C1 is the
full formal condition and is counted once. Actual SAM service availability, a
frozen runtime, and a separately approved cumulative budget are required before
execution. Prompt engineering is a common condition, not an ablated factor.
