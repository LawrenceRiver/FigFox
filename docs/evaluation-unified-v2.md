## What v2 measures

Eighteen criteria cover content, relationships/structure, readability, editability, material fidelity and chart/data properties. The package reports pass/fail/unknown/NA, evidence coverage, critical failures and usability status. It does not define a numerical utility total or authorize a 10-point conversion.

A verified semantic inventory, actual editing evidence and software operation records cannot be generated by setting flags in model JSON. We therefore preserve two separate layers:

1. **Strict rule results** produced by the supplied unmodified package. Missing human-signed inventories and actual editing/round-trip evidence remain unknown. Model outputs are imported only into `model_reviews` with `verification=unverified`.
2. **Model screening with an explicit protocol transition.** The original run made two isolated DeepSeek reviews of available candidates, using the same registry, canonical source/candidate full views and fixed quadrant crops. The user then requested no further paid assessment calls and direct review in the current chat. The completed delivery therefore selects one full D01–D18 primary review for each of 559 renderable candidates: 481 existing API reviews and 78 actual in-chat visual reviews. One malformed AFE SVG remains an explicit file failure. Existing second API reviews remain supplementary; the report does not claim uniform double judging or independent human replication.

API review inputs omit method labels and other judge outputs. In-chat inspection sheets use opaque candidate panel labels, but the assistant has project/method context: this is not equivalent blinding. Reviewer provenance and per-method origin counts are explicit. Each Dxx is one whole-image screening slot, not an exhaustive semantic-unit inventory. API and chat judgments may differ in conservatism; mixed-origin descriptive distributions cannot establish a verified ranking or causal improvement. Missing evidence stays unknown.

The user-directed stop remains enforced: no additional paid scoring requests. The 961 successful API responses before the stop cost an estimated USD 7.003177692 at configured rates, not an invoice. Direct in-chat review made zero additional external API calls; chat token usage is unavailable and recorded as null, not zero. Historical partial/invalid responses and costs are retained.

D13/D14/D16 cannot be passed without actual selection/edit/save/reopen evidence. D17 has no automatically verified material pairing and D18 has no verified underlying numeric data; no missing evidence becomes NA or a measured pass. A parser can confirm malformed SVG, but successful XML parsing is only a structural proxy.

The main vendor comparison uses FigFox S1C1 and the same three external methods; the other three FigFox conditions stay visible in the ablation table. Any formal all-criteria usable result still requires the evidence demanded by v2. File availability, model screening and human verification are separate columns.

Assessment request IDs, actual responses, input/source/artifact hashes, token usage and configured-rate cost estimates are retained locally. Evaluation is separately tracked from generation. Historic generation failures and unknown-charge reserves are not reset. The previously authorized condition budgets remain enforced; vendor assessment expenditure uses an explicitly labeled administrative shared allocation, not a claim about vendor generation costs.
