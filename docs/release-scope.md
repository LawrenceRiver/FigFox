# Public release scope

This repository includes the API runner, its rendering tools and prompts, the standalone FigFox Skill, and offline checks. The [validation notes](validation-factual.md) describe what was tested. The [source hashes](source-hashes.json) identify the recorded versions of core files.

## Figures

The cover was generated with FigFox Generate V2 and reconstructed using the FigFox Skill. It incorporates illustrations from the project’s architecture figure. The architecture and reconstruction examples use author-supplied figures. The [asset record](assets/asset-provenance.json) identifies their sources and files.
